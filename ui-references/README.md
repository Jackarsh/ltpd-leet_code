# UI / UX Reference Images

Place your UI/UX inspiration, wireframes, screenshots, or design mockup images in this directory (`ui-references/`).

### Supported File Formats
- PNG (`.png`)
- JPEG / JPG (`.jpg`, `.jpeg`)
- WebP (`.webp`)
- SVG (`.svg`)

### Suggested Naming (Optional)
Naming images by page or section makes them easy to identify:
- `dashboard-reference.png`
- `leaderboard-layout.png`
- `profile-heatmap.png`
- `gender-war-charts.png`
- `card-studio-theme.png`
- `admin-portal.png`
- `navigation-or-sidebar.png`
- `animation-example.png`

### What Happens Next
1. Drop your reference images into this folder: `ui-references/`.
2. Tell me whenever you have added the images.
3. I will visually inspect and analyze each image (color palette, typography, layout hierarchy, card styling, and micro-animations).
4. I will create an Implementation Plan and ask targeted questions to align on your exact design choices.
5. We will break down the changes into granular tasks and iteratively build the UI/UX, animations, and frontend components with continuous feedback loops.
